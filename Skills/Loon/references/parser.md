# Loon 解析器参考

这份文档用于说明资源解析器的输入、类型和最小模板。

## 适用范围

- 解析器目前只支持对**订阅节点资源**生效。
- 不要把解析器描述成可以通用处理规则、复写、脚本或插件资源。
- 如果用户要处理规则、复写、脚本或插件，应优先按对应配置段、插件或远程资源本身的语法处理，而不是建议使用解析器。

## 解析器里常用的变量

- `$resource`：原始订阅节点资源内容
- `$resourceType`：资源类型；当前可按订阅节点处理
- `$done(result)`：返回处理后的订阅节点内容

## 资源类型

- `1 = nodes`

## 最小模板

```javascript
var result = $resource

// 在这里对订阅节点内容做过滤、替换或重组

$done(result)
```

## 理解方式

可以把解析器理解成下面这几步：

1. 读取原始订阅节点内容
2. 对节点内容做过滤、替换或重组
3. 返回新的订阅节点结果

## 回答建议

当用户问“解析器怎么写”“订阅怎么转换”“节点资源怎么预处理”时，可以按下面顺序说明：

1. 输入是订阅节点资源
2. 需要对节点做什么处理
3. 处理后的节点内容是什么格式
4. 最后怎样用 `$done(result)` 返回

如果用户问规则、复写、脚本、插件资源的预处理，先说明：解析器目前只支持订阅节点；再改用对应类型的 Loon 配置或插件方案。
